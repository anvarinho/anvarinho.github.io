# Existing portfolio fonts

Manrope (400–800) and Space Grotesk (400–700), Latin variable WOFF2 subsets, downloaded from Google Fonts on 22 October 2026. This is the same family/weight range as the portfolio's previous Google Fonts import. Font loading is now local, preloaded, and uses `font-display: swap`.

The corresponding SIL Open Font License files are included alongside the fonts.
