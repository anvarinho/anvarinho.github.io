03 / IMPLEMENTATION NOTES

Connect the pieces.

Separate web and API routes in one Django project

The route configuration includes the web application and an api/ namespace in the same project. This separates client-facing endpoints from website routes while retaining a shared server boundary.

Inspect the route configuration
Native interfaces around shared services

The portfolio’s iOS record lists SwiftUI and Foundation; its Android record lists Jetpack Compose, Retrofit, and OkHttp. These are distinct native client implementations. The historical project record describes their connection to the Django server; released binaries are not available for independent inspection here.

Notifications are a separate integration

Firebase Cloud Messaging and iOS UserNotifications are named in the project record. That establishes the recorded notification stack, without asserting a particular delivery workflow, reliability figure, or current configuration.
